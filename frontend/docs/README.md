# 📄 Documentação & Specs do Frontend

Esta pasta é destinada aos documentos de planejamento, especificações de telas, fluxos de usuário e Design System do frontend.

### Conteúdos previstos:
- **Design System Specs:** Padrões visuais (paleta de cores, tipografia, espaçamentos com Tailwind).
- **Especificações de Componentes:** Estrutura e propriedades de componentes reutilizáveis (cards do feed, botões, modais, bottom bar).
- **Fluxos & Wireframes:** Mapeamento de navegação mobile e desktop (feed, busca, postagem rápida de itens, perfil).
- **Plano de Responsividade:** Regras e breakpoints para adaptação em smartphones e telas maiores.
