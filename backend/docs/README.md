# 📄 Documentação & Specs do Backend

Esta pasta é destinada aos documentos de planejamento, especificações e arquitetura do backend.

- **Regras de Negócio & Fluxos:** Documentação de fluxos de autenticação, postagem de itens, comentários e devoluções.
- **Planos de Integração:** Especificações para notificações, upload de imagens e armazenamento.
